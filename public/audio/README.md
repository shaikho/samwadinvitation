`song.mp3` is the background song. It starts very quietly when the guest opens the invitation and rises to about 70% volume as they scroll down.

- It's a 96 kbps re-encode of the original 320 kbps file (8.4 MB instead of 28 MB), so it streams quickly on phones.
- To change the song, replace `song.mp3` and keep the same name. If the file is missing, a soft generated music-box melody plays instead.
